## 2024-05-18 - Visible Triggers for Keyboard Shortcuts
**Learning:** Found a search palette in Vault-Web triggered exclusively by `Ctrl+K` with no visible UI button. This is a critical discoverability and accessibility issue, especially for users relying on mouse/touch or those unaware of the shortcut.
**Action:** Always ensure global keyboard shortcuts are paired with a persistently visible, accessible UI element (like a button) that both triggers the action and advertises the shortcut key.
