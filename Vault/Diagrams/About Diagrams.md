# Diagrams (Excalidraw)

Excalidraw is enabled for hand-drawn visuals — unit circles, function transformations, triangle setups — for the times a sketch beats text.

**To create one:** right-click the **Diagrams** folder → New → **Excalidraw drawing** (or open the Command palette and run *Excalidraw: Create new drawing*). Embed it in any note with `![[Your Drawing]]`.

You won't need it often — it's here so it's ready when you do. Good future candidates:
- [[M11 Preparing for Trigonometry]] — a labeled unit circle
- [[M07 Transformations]] — before/after graph shifts
- [[M14 Applications of Trigonometry]] — triangle diagrams for Law of Sines/Cosines
