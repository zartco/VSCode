# Polynomials

A polynomial is an expression consisting of monomials combined by addition or subtraction. A monomial is a number, a variable, or the product of a number and one or more variables with whole-number exponents. 

Polynomials are named using a two-name system (binomial nomenclature):
- **By highest exponent (degree):** Constant (0), Linear (1), Quadratic (2), Cubic (3), Quartic (4), $n^\text{th}$ degree polynomial.
- **By number of terms:** Monomial (1), Binomial (2), Trinomial (3), $n$-term polynomial.

> [!example] Quick example
> $6x^4 + 9x^2 - 4$ is a quartic trinomial. $(x+3)(x-5)=x^2-2x-15$.
