# U1.1 Definition of Polynomials

## Module 1 Introduction
Polynomials are foundational mathematical structures used frequently to model real-world situations. For instance:
- **Revenue** can be modeled by a polynomial, such as $250x - 2x^2$.
- **Cost** can be modeled by a polynomial, such as $3000 + 150x + 3x^2$.

In this module, you will learn to perform the four basic mathematical operations (addition, subtraction, multiplication, and division) on polynomials. You will also review square roots and rational exponents to assist with these operations. These basic skills will be utilized throughout Precalculus and in subsequent advanced math courses.

---

## Algebraic Expressions: Key Terminology
Before diving into polynomials, it is important to review the components of an algebraic expression. An **algebraic expression** (e.g., $-7 + 10x$) is defined as a mathematical phrase that combines variables, constants, and mathematical operations. 

- **Variable**: A letter used to represent an unknown value that can change (e.g., $x$ or $y$).
- **Constant**: A known value that does not change (e.g., $4$, $-7$, or $8$).
- **Term**: Each individual component of an algebraic expression separated by addition or subtraction. For example, the expression $x^3 + 3y - 5ab + 4$ consists of four terms: $x^3$, $3y$, $-5ab$, and $4$.
- **Coefficient**: The numerical factor of a term. For example, the coefficient of $3y$ is $3$, and the coefficient of $-5ab$ is $-5$ (meaning $ab$ is multiplied by $-5$). If no coefficient is explicitly written, it is assumed to be $1$ (e.g., $x^3$ has a coefficient of $1$).
- **Exponent**: Exponents provide a simplified way to express repeated multiplication. In $x^3$, $x$ is the **base** and $3$ is the **exponent**. This means $x \times x \times x$, and is read as "$x$ raised to the power of $3$."

### Like Terms
Particular terms in an algebraic expression are known as **like terms** if they contain *exactly the same variables raised to exactly the same power*. They may have different coefficients. 
- **Examples of Like Terms**: $5xy$ and $3xy$ (both variables $x$ and $y$ are to the first power). 
- **Examples of Unlike Terms**: $5xy$ and $5xy^2$ (in the first term, $y$ is raised to the first power; in the second, $y$ is squared). $6x^2$ and $x^3$ are unlike terms because the variable $x$ has different powers.
- **Note**: All constant numbers are considered like terms.

---

## What is a Polynomial?
A **monomial** is a special kind of term. It is defined as a number, a variable, or the product of a number and one or more variables.

A **polynomial** is an expression consisting of one or more monomials combined using addition or subtraction. Note that coefficients in a polynomial can include square roots (e.g., $\sqrt{2}y^2$).

### Restrictions on Polynomials
There are strict rules that determine whether an expression qualifies as a polynomial. A polynomial **cannot** include:
1. Division by a variable (e.g., $\frac{5}{x}$).
2. An infinite number of terms.
3. A variable raised to a negative exponent (e.g., $x^{-2}$).
4. A variable raised to a non-integer or fractional exponent (e.g., $x^{1/2}$).

---

## Naming Polynomials (Binomial Nomenclature)
Polynomials are described using a two-name system. Before naming a polynomial, ensure it is completely simplified by combining all like terms.
1. The **First Name** describes the highest exponent, also known as the **degree** of the polynomial.
2. The **Last Name** describes the **number of terms** in the simplified polynomial.

### First Name: By Degree
| Degree | Name | Example |
| :---: | :--- | :--- |
| $0$ | Constant | $8$ |
| $1$ | Linear | $3x + 5$ |
| $2$ | Quadratic | $4x^2 - 9x + 14$ |
| $3$ | Cubic | $-9y^3 + 11$ |
| $4$ | Quartic | $\frac{3}{7}x^4 - 6x^2 + y$ |
| $>4$ | $n^{\text{th}}$ degree polynomial | $x^6 - 4y^3$ (6th degree polynomial) |

### Last Name: By Number of Terms
| Number of Terms | Name | Example |
| :---: | :--- | :--- |
| $1$ | Monomial | $7x^5$ |
| $2$ | Binomial | $-2x^2 + 5$ |
| $3$ | Trinomial | $4x^2 + 8x - 3$ |
| $>3$ | $n$-term polynomial | $3x^3 - 3x^2 + 5x - 5$ (4-term polynomial) |

**Naming Examples**:
- $6x^4 + 9x^2 - 4$: The highest degree is $4$, and there are $3$ terms. This is a **quartic trinomial**.
- $-14x^7$: The degree is $7$, and there is $1$ term. This is a **7th degree monomial**.

---

## Combining Like Terms
To simplify algebraic expressions and combine like terms, you simply add or subtract their coefficients. Sometimes it is helpful to rewrite the polynomial in descending order (from the term with the highest power to the term with the lowest power).

### Examples
**Example 1: Combining Monomials**
$$2x^5 + (-x^5) = 2x^5 - 1x^5 = (2 - 1)x^5 = 1x^5 = x^5$$

**Example 2: Multiple Variables**
$$8xy + 4xy = (8 + 4)xy = 12xy$$
$$8y + 4y - 3y = (8 + 4 - 3)y = 9y$$

**Example 3: Simplifying a Polynomial**
Simplify the expression: $6x^3 - 15x^2 - 4x^3 + 5$
- **Identify like terms:** $6x^3$ and $-4x^3$.
- **Combine:** $(6x^3 - 4x^3) - 15x^2 + 5 = 2x^3 - 15x^2 + 5$
- **Classification:** Cubic trinomial.

**Example 4: Learn by Doing**
Simplify the expression: $5x^4 - 2x^2 + x^3 - 9 - 3x^2 + 4x^3$
- **Identify like terms:** 
  - $x^3$ terms: $x^3$ and $4x^3$
  - $x^2$ terms: $-2x^2$ and $-3x^2$
- **Combine:** $5x^4 + (1 + 4)x^3 + (-2 - 3)x^2 - 9$
- **Simplified form:** $5x^4 + 5x^3 - 5x^2 - 9$
- **Classification:** Quartic 4-term polynomial.

**Example 5: Did I Get This?**
Simplify and classify the polynomial: $4y^5 - 2y^3 + y^3 - 4y^5 - 3y + 7y$
- **Identify like terms:**
  - $y^5$ terms: $4y^5$ and $-4y^5$ (these cancel out)
  - $y^3$ terms: $-2y^3$ and $y^3$
  - $y$ terms: $-3y$ and $7y$
- **Combine:** $(4 - 4)y^5 + (-2 + 1)y^3 + (-3 + 7)y$
- **Simplified form:** $-y^3 + 4y$
- **Classification:** The highest exponent is $3$ (cubic) and there are two terms (binomial). Therefore, it is a **cubic binomial**.
