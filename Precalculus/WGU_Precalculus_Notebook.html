Solving Linear Equations

1. What is a linear equation?

An equation is just two expressions joined by an equals sign — a claim that the left side and the right side have the same value. A linear equation is the simplest, friendliest kind: the variable (usually \(x\)) appears only to the first power. No \(x^2\), no \(\sqrt{x}\), no \(x\) in a denominator — just \(x\) by itself, possibly multiplied by a number and added to others.

“Linear” literally means “line”: if you graphed it, you’d get a straight line. Here is how the textbook states it formally:

Snapshot — OpenStax College Algebra 2e, §2.2. Here \(a\) and \(b\) are just numbers; \(a\ne 0\) keeps a real \(x\) in the equation.

So \(2x+5=13\) is linear (\(a=2,\ b=5\)-ish after rearranging). Something like \(x^2 = 9\) is not — that’s a quadratic, which is Module 6.

2. The big idea: an equation is a balance

Picture an old-fashioned balance scale. The equals sign is the pivot in the middle. Whatever sits on the left weighs exactly the same as whatever sits on the right — that’s what “\(=\)” promises. The scale is perfectly level.

3. The tools: properties of equality

“Do the same thing to both sides” has four official versions. They sound fancy, but you already use them instinctively:

Addition Property

If \(a=b\), then \(a+c=b+c\). Add the same number to both sides.

Subtraction Property

If \(a=b\), then \(a-c=b-c\). Subtract the same number from both sides.

Multiplication Property

If \(a=b\), then \(ac=bc\). Multiply both sides by the same number.

Division Property

If \(a=b\), then \(a/c=b/c\) (with \(c\ne0\)). Divide both sides by the same number.

The textbook bundles these with one more tool you’ll need — the distributive property — into a short list of legal moves:

4. A picture for negative numbers

You nailed \(-4-(-6)=2\), but since signs trip up almost everyone, here it is on a number line. The key fact: subtracting a negative is the same as adding. So “\(-4\) minus \(-6\)” means “start at \(-4\) and move 6 to the right.”

5. One strategy that solves them all

“Until now we have dealt with solving one specific form of a linear equation. It is time now to lay out one overall strategy that can be used to solve any linear equation. Some equations we solve will not require all these steps, but many will.” — OpenStax Elementary Algebra 2e, §2.4

Here is that strategy, straight from the book:

Snapshot — OpenStax Elementary Algebra 2e, §2.4 — the five-step general strategy.

In plain language, the same five steps look like this:

1SimplifyDistribute and combine like terms on each side.
2Variables togetherMove all \(x\)-terms to one side.
3Numbers togetherMove all plain numbers to the other side.
4Coefficient → 1Divide to get \(x\) by itself.
5CheckPlug the answer back in.

6. Worked examples

Each line shows the move on the left and the reason on the right. Notice every example follows the same five-step rhythm.

Example A — a two-step equation review
\(2x + 5 = 13\)Starting equation
\(2x + 5 - 5 = 13 - 5\)Subtract 5 from both sides (Subtraction Property)
\(2x = 8\)Simplify
\(\dfrac{2x}{2} = \dfrac{8}{2}\)Divide both sides by 2 (Division Property)
\(x = 4\)Solution
✓ Check: \(2(4)+5 = 8+5 = 13\). True — so \(x=4\) is correct.
Example B — variables on both sides new today
\(3x + 2 = x + 10\)Starting equation
\(3x - x + 2 = x - x + 10\)Subtract \(x\) from both sides — gather the variables (Step 2)
\(2x + 2 = 10\)Simplify
\(2x = 8\)Subtract 2 from both sides (Step 3)
\(x = 4\)Divide both sides by 2 (Step 4)
✓ Check: left \(3(4)+2=14\); right \(4+10=14\). Both sides equal 14.
Example C — using the distributive property step 1
\(2(x + 4) = 18\)Starting equation — parentheses first
\(2x + 8 = 18\)Distribute the 2: \(2\cdot x + 2\cdot 4\) (Step 1)
\(2x = 10\)Subtract 8 from both sides
\(x = 5\)Divide both sides by 2
✓ Check: \(2(5+4)=2(9)=18\). Correct.
Example D — the whole strategy at once all 5 steps
\(5(x - 1) = 2x + 7\)Starting equation
\(5x - 5 = 2x + 7\)Distribute the 5 (Step 1)
\(3x - 5 = 7\)Subtract \(2x\) from both sides (Step 2)
\(3x = 12\)Add 5 to both sides (Step 3)
\(x = 4\)Divide both sides by 3 (Step 4)
✓ Check: left \(5(4-1)=15\); right \(2(4)+7=15\). Balanced.

7. Watch out for these

  • Changing only one side. If you subtract 5, subtract it from both sides. The scale must stay level.
  • Sign slips with negatives. \(-(-6)=+6\). Rewrite “minus a negative” as “plus” before simplifying.
  • Distributing to only the first term. \(2(x+4)=2x+8\), not \(2x+4\). The multiplier hits everything in the parentheses.
  • Dividing too early. Combine like terms and isolate the \(x\)-term first, then divide by its coefficient last.
  • Skipping the check. Substituting your answer back is a free way to catch errors — always do it.

8. Your practice

The first three are from our session. Then two “stretch” problems that fold in the distributive property. Work each on paper, then reveal the full steps.

1Solve \(5x - 3 = 2x + 9\)
  • Subtract \(2x\): \(3x - 3 = 9\)
  • Add 3: \(3x = 12\)
  • Divide by 3: \(x = 4\)
✓ \(5(4)-3=17\) and \(2(4)+9=17\).
2Solve \(4x + 1 = 7x - 8\)
  • Subtract \(4x\): \(1 = 3x - 8\)
  • Add 8: \(9 = 3x\)
  • Divide by 3: \(x = 3\)
✓ \(4(3)+1=13\) and \(7(3)-8=13\).
3Solve \(2x - 6 = 5x\)
  • Subtract \(2x\): \(-6 = 3x\)
  • Divide by 3: \(x = -2\)
✓ \(2(-2)-6=-10\) and \(5(-2)=-10\). A negative answer is perfectly fine.
4Solve \(3(x - 2) + 5 = 14\)stretch
  • Distribute: \(3x - 6 + 5 = 14\)
  • Combine like terms: \(3x - 1 = 14\)
  • Add 1: \(3x = 15\)
  • Divide by 3: \(x = 5\)
✓ \(3(5-2)+5 = 3(3)+5 = 14\).
5Solve \(2(3 - x) = x + 9\)stretch
  • Distribute: \(6 - 2x = x + 9\)
  • Subtract \(x\): \(6 - 3x = 9\)
  • Subtract 6: \(-3x = 3\)
  • Divide by \(-3\): \(x = -1\)
✓ \(2(3-(-1))=2(4)=8\) and \((-1)+9=8\).

Key takeaways

  • An equation is a balance — do the same operation to both sides.
  • Follow the five steps: simplify → variables together → numbers together → coefficient to 1 → check.
  • Distribute across all terms in parentheses.
  • Subtracting a negative adds: \(a-(-b)=a+b\).
  • Always check by substituting your answer into the original equation.
