# CS50 Python & HTML Exercises

Python and HTML scripts written while working through [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/).

Each file covers a specific introductory programming concept and runs on its own — no external libraries are needed.

## File Contents

| File | Concept |
|---|---|
| `hello.py` / `helloworld.py` | Print statements, basic I/O |
| `calculator.py` / `calculator1.py` | Functions, arithmetic |
| `compare.py` | Conditionals |
| `parity.py` | Modulo operator |
| `loops.py` | `for` loops, `range()` |
| `cat.py` | String input and manipulation |
| `grade.py` | Nested conditionals |
| `house.py` | Functions, control flow |
| `list.py` | Working with arrays/lists |
| `hogwarts.py` | Dictionaries / object-like data |
| `html_skeleton.html` / `index.html` | Basic HTML structure |

## Running the scripts

Because these are self-contained learning exercises, they can be run directly using Python from the command line:

```bash
python <script_name>.py
```

Requires Python 3.x — no `pip install` commands or virtual environments are needed.
