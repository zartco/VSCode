## 2024-07-28 - Visible Search Trigger
**Learning:** Discoverability issue identified: Global keyboard shortcuts (like Ctrl+K for search) without visible UI indicators severely limit accessibility and usability.
**Action:** Lifted search palette state to parent application shell to pair the hidden keyboard shortcut with a persistent, styled toggle button in the main taskbar that explicitly advertises the shortcut, ensuring all users can discover and interact with the feature.
